# 免费版基础大运趋势规则规范

更新日期：2026-11-03  
版本：FREE-LUCK-TREND v0.2  
状态：产品边界已确认；规则口径待引擎核对、测试命例验证；尚未实现代码。  
适用范围：L0 免费排盘的单步大运基础趋势提示。  
不适用：完整大运吉凶断语、格局判断、具体事件预测及专业命理分析。

## 1. 产品边界

免费版回答一个有限问题：**这一步大运的天干、地支五行，与本站现有简化扶抑参考呈现什么基础对应关系？**

免费版不回答“这十年整体究竟吉还是凶”，也不宣称完成传统命理意义上的断运。前台名称统一使用“基础大运趋势”或“基础趋势参考”，不使用“完整大运吉凶”“专业断运”等表述。

免费版只使用现有排盘结果和已经公开说明的简化扶抑参考，输出有限的趋势提示。不得为了给每一步大运贴标签而增加未经验证的综合算法。

## 2. 免费版允许使用的资料

可以使用：
- 本命日主及其五行。
- 本站现有简化扶抑参考的结果，包括其强弱分类及扶抑参考五行。
- 所选大运天干五行、地支主气五行。
- 大运天干十神、地支主气十神，作为辅助资料展示，不单独决定趋势。
- 大运干支、起止年份和年龄范围等排盘事实。

基础趋势的初步规则口径：
1. 先读取本命简化扶抑参考；若结果缺失、异常或为中和而没有明确扶抑方向，不强行给出有利/不利等级。
2. 分别检查大运天干五行和地支主气五行，是否落在该简化参考列出的扶助方向或制泄方向。
3. 天干与地支方向一致时，才允许给出“基础偏有利”或“基础偏谨慎”的提示。
4. 天干与地支方向不一致、一个命中而另一个无明确方向时，显示“因素交错”，不强行判吉凶。
5. 若出生时辰未知、关键数据缺失或排盘口径存在未解决的不确定性，显示“三柱参考”或“暂不判断”，不得伪装成完整四柱结论。

上述规则只描述简化模型内部的对应关系。正式编码前，必须核对引擎返回字段及现有页面实际传参，并用测试命例验证，不得凭文档名称猜测字段。

## 3. 免费版明确不做的判断

以下内容全部属于未来 L1/L2 专业付费分析，不得作为免费版基础趋势的计算条件或结论依据：
- 月令司令、分日用事及完整月令分析。
- 日主得时、得势、得地的综合旺衰判断。
- 格局识别、格局成败、破格与救应。
- 完整用神、喜神、忌神判断；不把现有简化扶抑结果包装成传统完整用神。
- 逐日主、逐月令的调候分析。
- 通关、制化、五行力量胜负及复杂根气分析。
- 大运与本命四柱之间刑、冲、合、会的实际作用、合化成立与否。
- 大运对月令、日支、关键透干和格局结构的综合影响。
- 大运与流年叠加后的综合判断。
- 具体事业、财务、婚姻、健康、迁移、灾祸等事件断语及精确应期。

这些项目不是不重要，而是需要更完整的规则、证据和人工复核，不能压缩成免费版的简单标签。

## 4. 趋势标签与文案边界

建议首版只保留四种状态：
- **基础偏有利**：大运天干与地支主气均落在简化扶抑参考的同一扶助方向。只表示基础模型方向一致，不代表现实结果必然顺利。
- **基础偏谨慎**：大运天干与地支主气均落在简化扶抑参考的同一制泄方向。只表示基础模型方向一致，不代表必然发生不利事件。
- **因素交错**：大运天干与地支主气对应方向不一致，或只有一方有明确对应。
- **暂不判断**：简化扶抑参考中和、资料缺失、出生时辰未知导致本版不适合分级，或数据校验未通过。

不得把上述标签改写成“必吉、必凶、发财、破财、升职、婚变、疾病”等确定性断语。不得显示百分比、运势分数或成功概率。

## 5. 页面展示原则

每步大运只显示：
- 基础趋势标签。
- 一句说明，指出大运天干、地支主气与简化扶抑参考的对应方向。
- 一条醒目但简短的范围提示：“这是基础五行趋势参考，不是完整命局断运。”
- “了解专业分析范围”入口（未来服务尚未上线时，只可展示规划说明，不得出现虚假购买入口）。

十神、藏干、十二长生和干支关系仍按原有排盘资料展示；它们不自动转成吉凶结论。判断卡片不得挤压四柱主盘和大运时间轴。

## 6. 现有引擎限制

现有 `computeFavorableElement` 使用 R20 简化权重模型：可见天干、地支主气和藏干按固定权重统计，月柱加权；其输出不是完整传统格局取用，也没有充分处理根气、合冲、司令和复杂制化。

现有调候简则仅覆盖夏月取水、冬月取火，不等于逐日主、逐月令的完整调候法。

现有 `stemRelation`、`branchRelations` 提供关系命中资料，不负责判断合化、力量胜负、格局成败或关系对原局的实际影响。

因此：
- 免费趋势不得将简化扶抑参考包装为传统完整用神。
- 不得把接口返回的关系命中直接纳入吉凶等级。
- 不得用单个十神、五行数量、神煞、冲合或十二长生直接决定趋势。
- 引擎资料与规则不匹配时，输出“暂不判断”，而不是补造数据。

## 7. 未来付费专业分析范围

专业分析可在未来独立建设，至少需要逐步具备：
1. 月令、司令与格局基础辨析。
2. 日主旺衰、得时得势得地、根气和透干综合判断。
3. 扶抑、调候、通关等不同取用角度及其冲突处理。
4. 大运干支整体、盖头截脚、原局制化和刑冲合会的实际作用。
5. 大运与流年的分层及综合影响。
6. 每项结论的盘面证据、古籍依据、流派口径、不确定性和人工复核记录。

付费分析不能仅因收费就降低准确性要求；复杂结论必须有规则、测试和可追溯证据。

## 8. 古籍依据及其使用边界

以下典籍用于未来专业规则研究，不代表免费版已经实现其完整理论：
- 《渊海子平》卷三《论大运》：强调大运须随格局喜忌推之，不可执一。
- 《滴天髓阐微·月令》《岁运》：讨论月令、得时得势得地、岁运作用及干支配合。
- 《三命通会》卷二《论大运》及《总论岁运》：强调命局根基、用神需求及岁运与原局关系。
- 《渊海子平》卷一《论五行生克制化各有所喜所害例》：说明五行生克须随强弱和结构变化，不可机械定吉凶。

古籍原理用于指导专业分析规则，不可把古籍中的历史性灾祸断语直接改写成现代用户的现实预言。不同版本和流派存在差异时，必须标明口径。
