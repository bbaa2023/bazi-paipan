# 大运吉凶判断规则规范（第一版）

更新日期：2026-11-03  
版本：DA-YUN-RULES v0.1  
状态：理论依据与规则边界初稿；尚未实现代码，尚未完成命例回归验证。  
适用范围：免费排盘 L0 的单步大运整体倾向判断。  
不适用：具体事件保证、疾病诊断、投资建议、婚姻结论、寿夭断语及精确应期。

## 1. 目标与基本原则

本模块要回答的是：某一步大运相对于本命原局，整体呈现哪些助益、压力或结构变化；结论必须能指出具体命盘证据。

采用“经典原理 + 明确的现代程序化口径”：
- 经典原文用于确定分析原则，不把古籍中的所有旧式断语直接复制成现代产品结论。
- 引擎字段用于提供可核验的排盘事实，不把接口字段本身误当成吉凶结论。
- 每条判断都必须能追溯到本命柱位、大运干支、藏干、十神、五行及实际关系。
- 不用单一五行数量、单一十神、单一合冲或神煞决定整步大运。
- 证据不足时输出“暂无法综合判断”或降低判断把握，不为了填满界面强行贴吉凶标签。

## 2. 经典依据及其程序化含义

### 2.1 《渊海子平》卷三《论大运》

关键原理：
- 大运从月令起，论运须联系月令、格局与命局根苗。
- 原文提出“大运看支”，同时论干支配合，不能把大运天干、地支割裂成两个互不相关的结论。
- 原文举出不同日主行不同五行运的例子后，明确提醒“须随格局喜忌推之，不可执一”。
- 原文又提出“干旺宜行衰运，干弱宜旺运”，强调旺衰与运势之间需要平衡判断。
- 原文对生旺、衰绝、冲克等另有论述，但不能将单一长生状态或某种关系机械等同吉凶。

程序化规则：
1. 先分析原局，再分析大运；不先给大运五行贴固定吉凶。
2. 以大运地支及其藏干作为重要观察对象，同时检查天干是否透出、受生、受制及是否有根。
3. 大运作用必须结合本命月令、日主状态和命局所取用神/喜忌。
4. 不能把“甲乙木日主走木运”等固定口诀写成通用断语。

### 2.2 《滴天髓阐微》《月令》《岁运》

关键原理：
- 《月令》强调月令为提纲，并要求辨认月令中实际司令之气；得时、得势、得地不可偏废。
- 《岁运》提出“休囚系乎运，尤系乎岁，战冲视孰降，和好视孰切”。
- 任氏注强调大运要把干支合看，不能上下截开；并讨论盖头、截脚、根气、原局制化对吉凶的增减。
- 同一种五行即使被视为喜神，也可能因盖头、截脚、无根或原局冲克而减力；看似不利的五行也可能因有制、有化而不直接成凶。

程序化规则：
1. 旺衰不能只用五行数量代替，至少要分别考虑得时、得势、得地。
2. 大运干支必须作为一个整体评估：检查天干坐支是否承载、是否盖头/截脚、是否有根及是否受原局制化。
3. 冲、合、刑、害只表示作用关系；判断结果还要看参与双方力量、位置、是否有制化以及是否影响关键结构。
4. 大运与流年分层：大运作为十年背景，流年作为阶段内触发因素；不能用某一年冲合直接给整步十年大运定性。

### 2.3 《三命通会》卷二《论大运》及《总论岁运》

关键原理：
- 先以三元、四柱、五行生死、格局定根基，再考究运气。
- “凡行运，在干兼用地支之神，在支则弃天干之物”及“用神者欲运制之益，用神者欲运生之”等论述，强调不同用神的需求不同，不能对所有命局套同一喜忌。
- 官、煞、财、印、食神等各有“宜生、宜制、宜扶、忌伤、忌劫”等不同条件。
- 《总论岁运》强调运与流年互为表里，并特别讨论岁运与月柱、日柱之间的冲克及原局是否有救应。

程序化规则：
1. 必须先定原局分析基础，不能只读大运柱本身。
2. 十神的利弊要结合日主承受能力、原局配置及其在格局中的作用，不做“正官必吉、七杀必凶、财星必吉”等固定标签。
3. 大运与月柱、日柱的冲合关系需要重点呈现，但不得把古籍中的旧式灾祸断语直接映射成现代事件。
4. 原局有无制化、通关、扶助，是判断关系影响的重要条件。

### 2.4 《渊海子平》卷一《论五行生克制化各有所喜所害例》

关键原理：
- 五行生克不是单向固定的好坏：旺者可能需要制化，弱者可能经不起克泄；生助过度也可能造成壅滞。
- 原文举出“土多金埋”“木多火炽”“水多木漂”等反向作用，并指出强弱不同，财、官杀、印、食伤作用会变化。

程序化规则：
1. 不以某元素数量多就判为有利或不利。
2. 需观察大运带来的五行是补偏、制衡、通关，还是加重原局偏枯。
3. 生扶不自动等于吉，克制不自动等于凶；关键是是否符合命局所需及是否过度。

## 3. 判断流程

### 第一步：确认分析前提

必须具备：
- 有效本命四柱；未知时辰则明确标记三柱分析。
- 性别已选择且大运序列已成功计算。
- 大运干支、步序及起止区间有效。
- 本命日主、月令、藏干和五行资料可读取。

以下情况降低判断把握或停止综合判断：
- 出生时刻未知，且起运范围跨越节气或可能改变关键排盘结果。
- 出生时刻接近节气边界、年/月柱存在口径敏感性。
- 关键引擎字段缺失、命盘无效或大运柱数据不完整。
- 旺衰、格局、用神判断出现冲突，现有规则无法可靠处理。

### 第二步：建立本命基础

至少记录：
- 日主五行、阴阳。
- 月令及月支藏干。
- 日主得时、得势、得地的证据。
- 天干透出、地支根气及藏干分布。
- 五行生克制化的主要路径。
- 当前采用的扶抑参考及调候参考，并明确它们是不同观察角度。

特别限制：
- 当前引擎 computeFavorableElement 的 R20 加权计分是一个简化模型：月柱加权、日主天干不计、地支主气和藏干按既定权重累加。它不是古籍中完整的格局取用法。
- 当前调候简则只覆盖夏月取水、冬月取火，不能代替逐日主、逐月令的完整调候体系。
- 因此第一版不得仅凭 score.verdict 或 fuYang.favorable 独立生成最终吉凶。

### 第三步：分析大运本身

对每一步大运分别读取：
- 天干五行、阴阳、十神。
- 地支五行、藏干及各藏干十神。
- 大运干支是否同气、相生、相克。
- 大运天干是否得地支承载、有根，是否存在盖头/截脚倾向。
- 地支对原局月令、日支及其他本命地支的作用关系。

十神解释规则：
- 十神是关系名称，不是固定吉凶标签。
- 财、官、印、食伤、比劫均需结合日主旺衰、原局结构、是否为所需、是否过量及是否受制化。
- 若无法确认格局取用，文案只能描述“出现某类十神力量/主题”，不能直接断发财、升职、婚变、疾病等事件。

### 第四步：分析大运对原局的作用

逐项检查：
1. 是否补足原局明显不足，或缓解过旺、过弱。
2. 是否加重原局已经偏重的五行力量。
3. 是否对月令、日主根气、关键透干产生明显作用。
4. 是否与本命四柱形成六合、六冲、六害、刑、自刑、半三合等关系。
5. 是否具备制化、通关或解救条件。
6. 是否触及已识别的格局关键点。

关系解释边界：
- 两两关系接口只返回规则命中，不等于合化成立。
- 半三合不能视为完整三合；完整三合、三会必须有全部不同成员。
- 六合、三合不得自动认定化气成功。
- 冲不自动判凶，合不自动判吉，刑害不自动推导具体现实事件。
- 若现有引擎未提供合化、旺衰力量、格局破损等可靠判定，则将相关内容列为“关系提示”，不纳入强结论。

### 第五步：综合结论

第一版采用定性规则归纳，不先设计未经验证的任意分数或百分比。

结论等级：
- 整体偏有利：主要助益明确，关键不利因素较少，且没有未解决的重大冲突。
- 相对有利：助益多于制约，但仍有明显条件或局部压力。
- 吉凶参半：有利与不利证据并存，或不同判断角度出现明显分歧。
- 相对承压：制约、消耗或结构冲突较明显，但仍存在制化、扶助或局部改善。
- 整体需谨慎：多个关键层面同时出现不利作用，且现有盘面中缺少足够制化/通关条件。
- 暂无法综合判断：关键基础不确定、规则冲突或证据不足。

注意：
- 等级表示传统规则下的盘面倾向，不是现实结果概率。
- “整体需谨慎”不等于灾祸；“整体偏有利”不保证成功。
- 不允许仅凭一个神煞、一个冲、一个十神或一项五行分布决定等级。
- 每个等级必须同时输出至少两条盘面证据；如果只有一条证据，应降级为局部提示或暂不判断。

## 4. 第一版输出结构

每一步大运建议输出：
- grade：五级倾向之一，或 insufficient。
- headline：一句简短结论。
- summary：一至三句整体说明。
- supportingEvidence[]：有利因素，含证据类型、命盘位置、干支/五行/十神、规则说明。
- challengingEvidence[]：需要留意的因素，同样包含可定位证据。
- balanceNotes[]：制化、通关、盖头、截脚、力量不纯等修正说明。
- uncertainties[]：未知时辰、格局未定、调候口径不完整、流派差异等。
- methodVersion、sourceReferences[]：规则版本及古籍篇目引用。

页面简版只展示：
- 整体倾向等级。
- 一句简要判断。
- 两至三条最重要依据。
- “查看判断依据”入口。

不得在免费版首屏展示大段古籍理论或复杂推导；完整依据可在展开区查看。

## 5. 现有引擎能力与缺口

已具备、可作为事实输入：
- computeBazi：四柱、日主、月令基础、藏干、五行统计。
- computeFavorableElement：简化旺衰计分、扶抑参考、有限调候简则。
- computeLuckPillars：大运干支、天干/地支十神、藏干十神、十二长生、时间范围。
- stemRelation / branchRelations：天干、地支两两关系。
- 页面已建立本命—所选大运—所选流年的关系对象及来源定位。

尚不足以直接做完整传统格局断运：
- 未建立可靠、覆盖多格局的自动格局识别与格局成败判断。
- 未建立完整月令分日司令计算及逐日主调候体系。
- 未建立可验证的五行根气、透干、党众、得时得势得地综合力量模型。
- 两两关系接口不负责合化成立、破格、通关和力量胜负判断。
- 当前简化旺衰计分不能直接等同传统用神体系。

因此第一版先做“可解释的基础大运倾向判断”，把无法可靠计算的高级格局项目明确列为限制，不虚构完整能力。后续逐项补充规则与测试，再扩大可自动判断范围。

## 6. 验证策略

代码实现前先建立人工核对命例集，至少覆盖：
- 身强与身弱。
- 得令、失令但得地、失令而得势等不同情况。
- 大运扶助、泄耗、克制及五行过旺反向为害。
- 喜神运但遇盖头、截脚、无根。
- 原局有制化与无制化。
- 大运支与月支、日支发生冲合刑害。
- 未知时辰及起运边界不确定。
- 同一命盘连续多步大运，检查等级变化是否有盘面理由。

每个案例记录：命盘输入、四柱、大运柱、引擎版本、规则版本、逐项证据、人工复核意见、分歧及修订原因。

不得以“程序输出符合预设文案”代替命理规则正确性验证；不得把网络命例的现代断语当作古籍原文。
