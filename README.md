# bazi-paipan｜独立八字排盘

部署目标：`https://bazi.xiulian.lat`。这是与 Halo 分离的静态网页项目。

## 当前首版

- 独立页面布局，不使用 Halo 文章模板。
- 本地内置上游浏览器引擎：`vendor/bazi-engine.web.js`。
- 输入公历年月日时分、经度（选填）、性别和换日口径。
- 展示四柱、引擎提供的五行统计、藏干、十神、纳音、原始计算详情。
- 在接口支持时尝试展示大运结果。
- 五行配色、响应式布局、轻量动效和减少动态效果的系统偏好支持。
- 不调用第三方排盘 API，不向外发送出生资料。

## 部署

请按 `docs/BAOTA_DEPLOY.md` 操作。宝塔站点根目录必须独立于 Halo。

## 上游引擎与许可

本项目使用 [bazi-atlas/bazi-engine](https://github.com/bazi-atlas/bazi-engine) 的浏览器 bundle。上游许可证保存在 `vendor/LICENSE.bazi-engine`，bundle 内原版权声明未删改。页面底部以简短文字链接到上游仓库。

## 当前限制

这是用于打通部署流程的简单首版，不代表完整功能验收。地支关系、十二长生、神煞、完整大运展示等模块将在确认当前引擎返回结构后继续完善。五行统计字段按引擎实际输出读取，不自行补造结果。
